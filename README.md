# Most-Wanted-Podcasts
Most Wanted Podcasts is a Python application that pulls the FBI's Ten Most Wanted list via the FBI API and cross-references it against Apple Podcasts (via the iTunes Search API) to surface true crime podcast episodes about a specific fugitive the user selects.

- Built a Python integration connecting the FBI’s Ten Most Wanted public API with the iTunes Search API to aggregate relevant true crime podcast episodes based on user-selected fugitives.

- Automated cross-referencing and data extraction by parsing complex JSON payloads across multiple endpoints, standardizing dynamic search queries for accurate episode matches.

- Designed a modular command-line application handling error edge cases, missing API responses, and rate-limiting across external endpoints.

- Leveraged AI-assisted development tools (GitHub Copilot, Claude) to prototype and refine a lightweight user interface for seamless query interactions.


# How to Run
1. Clone repository into an IDE
2. CD into src -> main
3. In terminal run python app.py
